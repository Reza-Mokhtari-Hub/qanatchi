# راهنمای گام‌به‌گام استقرار «قنات‌چی» روی رایانش لبه ابر آروان (ArvanCloud Edge)

> **نسخه آماده انتشار (فاز ۶.۱):** این راهنما مطابق با خروجی‌های واقعی ساخت تولید و تست‌های امنیتی به‌روزرسانی شده است. از آنجا که دسترسی مستقیم به صفحات `docs.arvancloud.ir` از این محیط ساخت امکان‌پذیر نبود (`HTTP 307` / Timeout)، محدودیت‌های دقیق پلن، نام بخش‌های داشبورد و جزئیات مسیرها باید هنگام استقرار در پنل کاربری ابر آروان شما تطبیق داده شوند. هیچ استقرار زنده یا تغییر DNS به‌صورت خودکار انجام نشده است.

---

## ۱. آماده‌سازی بسته تولید تکرارپذیر (Reproducible Release Build)

در سیستم محلی خود دستورات زیر را به‌ترتیب اجرا کنید:

```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. ساخت فایل واحد، کم‌حجم و سازگار با رایانش لبه (dist-edge/worker.js)
npm run build:edge

# ۳. بررسی کامل TypeScript (باید با ۰ خطا تمام شود)
npm run lint

# ۴. اجرای تمام ۴۵ تست خودکار (موتور بازی، کمپین، چالش‌ها، صدا، انیمیشن، کلاینت و Edge API)
npm test

# ۵. ساخت نسخه تولیدی فرانت‌اند با cross-env NODE_ENV=production و تفکیک Chunkهای تنبل (dist/)
npm run build
```

### خروجی‌های تولیدی تأییدشده:
1. **پوشه `dist/`**: نسخه استاتیک کاملاً بهینه‌سازی‌شده بازی (بیلد تولیدی React بدون هشدارهای توسعه، تفکیک تنبل صفحات فرعی با `React.lazy`، تصویر پس‌زمینه فشرده‌شده `149 KiB` در `dist/src/assets/images/`). بدون نیاز به سرور Node.js.
   - برای میزبانی روی زیرمسیر (مثلاً `/qanatchi/`) پیش از `npm run build` متغیر `VITE_BASE_PATH=/qanatchi/` را تنظیم کنید.
   - اگر API روی دامنه جداگانه‌ای میزبانی می‌شود، هنگام بیلد فرانت‌اند متغیر `VITE_API_BASE_URL=https://<api-domain>` را تنظیم کنید.
2. **فایل `dist-edge/worker.js`** (`~36 KiB` کم‌حجم‌شده، `~12 KiB` فشرده gzip): کد مستقل Edge API با الگوی رسمی `addEventListener("fetch", ...)`، با ممیزی خودکار نبود هیچ‌گونه وابستگی Node.js، Express، `process.env`، کلودفلر، کلید محرمانه یا حافظه موقت تست (`InMemoryTestStorageAdapter`).

## ۲. ساخت اپلیکیشن Edge API در پنل ابر آروان

1. وارد **پنل کاربری ابر آروان** شوید و بخش **رایانش لبه (Edge Computing)** را باز کنید.
2. گزینه **ساخت اپلیکیشن جدید (Create Application)** را انتخاب کنید و نامی مانند `qanatchi-api` بگذارید.
3. محتوای فایل **`dist-edge/worker.js`** را در ویرایشگر کد اپلیکیشن قرار دهید (یا فایل را بارگذاری کنید) و **انتشار (Deploy)** را بزنید.
4. از بخش **Console Log** و **تاریخچه نسخه‌ها (Deployments)** می‌توانید خروجی اجرا و شناسه هر نسخه را برای عیب‌یابی یا بازگشت سریع مشاهده کنید.

---

## ۳. تنظیم متغیرهای محیطی (Environment Variables)

در تنظیمات اپلیکیشن `qanatchi-api` به بخش **متغیرهای محیطی** بروید (هیچ مقدار محرمانه‌ای در کد فرانت‌اند یا مخزن قرار ندهید):

| نام متغیر | نوع پیشنهادی | توضیح |
| :--- | :--- | :--- |
| `APP_ENV` | متنی (Plain) | مقدار `production` (در `/api/v1/health` نمایش داده می‌شود). |
| `ALLOWED_ORIGINS` | متنی (Plain) | در صورت تفاوت دامنه فرانت‌اند و API، آدرس دقیق **`https://`** دامنه بازی (مثلاً `https://qanatchi.example.ir`) را وارد کنید. در محیط تولید (`production`) تنها دامنه‌های `https://` پذیرفته می‌شوند و `*`، `null` و `http://` به‌صورت خودکار رد می‌شوند (در محیط `development`، `http://localhost` مجاز است). در حالت هم‌دامنه (Same-Origin) خالی بگذارید. |
| `LEADERBOARD_STORAGE_DRIVER` | متنی (Plain) | تا زمان اتصال یک پایگاه‌داده پایدار از طریق درگاه HTTPS امن، خالی بگذارید تا API به‌صورت شفاف `503 STORAGE_NOT_CONFIGURED` برگرداند. |
| `LEADERBOARD_DATABASE_URL` | **رمزنگاری‌شده (Encrypted)** | فقط پس از راه‌اندازی درگاه HTTPS پایگاه‌داده پایدار تنظیم شود. |
| `LEADERBOARD_DATABASE_TOKEN` | **رمزنگاری‌شده (Encrypted)** | کلید احراز هویت درگاه پایگاه‌داده (در صورت راه‌اندازی در آینده). |

> **نکته مهم:** متغیر `EC_URL` توسط زیرساخت ابر آروان مدیریت می‌شود و نباید به‌صورت دستی تغییر داده شود.

## ۴. استقرار فایل‌های استاتیک بازی (`dist/`) و تنظیم SPA Fallback

1. یک سطل (Bucket) در **فضای ابری (Object Storage)** ابر آروان بسازید و دسترسی خواندن عمومی فایل‌های استاتیک آن را فعال کنید.
2. تمام محتوای پوشه `dist/` شامل `index.html`، پوشه `assets/` (تمام فایل‌های JS/CSS تفکیک‌شده) و پوشه `src/assets/` را در ریشه سطل بارگذاری کنید.
3. دامنه خود را در **شبکه توزیع محتوا (CDN)** ابر آروان متصل کنید (گواهی SSL رایگان به‌صورت خودکار صادر می‌شود) و مبدأ (Origin) را روی سطل فضای ابری تنظیم کنید.
4. **پشتیبانی از لینک‌های مستقیم SPA:** اطمینان حاصل کنید درخواست مسیر اصلی `/` با Query String (مانند `/?challenge=Q1-...`) به `index.html` هدایت شده و Query String حفظ می‌شود؛ برای مسیرهای فرعی ناموجود نیز در صورت نیاز `404 → index.html` تنظیم شود (به‌جز مسیر `/api/v1/*`).

---

## ۵. متصل کردن مسیرها (Routes) — معماری هم‌دامنه (Same-Origin)

در تنظیمات **مسیرها (Routes)** اپلیکیشن Edge روی دامنه متصل‌شده در CDN ابر آروان:

1. مسیر **`<yourdomain.ir>/api/v1/*`** را به اپلیکیشن Edge API (`qanatchi-api`) متصل کنید.
2. مسیر **`<yourdomain.ir>/*`** را روی میزبانی استاتیک `dist/` نگه دارید.
3. در این حالت (Same-Origin) فرانت‌اند بدون نیاز به `VITE_API_BASE_URL` و بدون پیچیدگی CORS به‌صورت مستقیم به `/api/v1/*` متصل می‌شود.

## ۶. بررسی سلامت پس از استقرار (Post-Deploy Health Checks)

پس از انتشار روی دامنه یا آدرس پیش‌فرض Edge، دستورات زیر را اجرا کنید:

```bash
# ۱. بررسی سلامت سرور لبه (باید 200 OK، تاریخ تهران و بدون هیچ رمز/کلیدی باشد)
curl -i https://<yourdomain.ir>/api/v1/health

# ۲. بررسی دریافت معمای روزانه رسمی از سرور (بر اساس Asia/Tehran)
curl -i https://<yourdomain.ir>/api/v1/daily

# ۳. بررسی وضعیت شفاف جدول امتیازات (تا پیش از اتصال پایگاه‌داده باید 503 STORAGE_NOT_CONFIGURED باشد)
curl -i https://<yourdomain.ir>/api/v1/leaderboards/daily

# ۴. بررسی محافظت CORS (برای دامنه نامعتبر نباید هدر Access-Control-Allow-Origin برگردد)
curl -i -H "Origin: https://evil.example.com" https://<yourdomain.ir>/api/v1/health
```

سپس در مرورگر موبایل و دسکتاپ بررسی کنید:
- صفحه اصلی، نقشه مناطق (یزد، کرمان، کاشان)، چالش روزانه، لینک رقابت دوستانه (`/?challenge=Q1-...`) و تنظیمات بدون خطای کنسول باز می‌شوند.
- پس از حل چالش روزانه، امتیاز محلی و امتیاز تأییدشده سرور (`Ranked Scoring v2`) به‌صورت جداگانه نمایش داده می‌شوند.
- با قطع اینترنت، کمپین ۲۴ مرحله‌ای، معمای روزانه و رکوردهای محلی بدون اختلال کار می‌کنند.

---

## ۷. دستورالعمل بازگشت به نسخه قبل (Rollback)

در صورت مشاهده هرگونه خطا پس از استقرار:
1. **بازگشت فوری Edge API:** در پنل رایانش لبه ابر آروان، از بخش **Deployments / History** اپلیکیشن `qanatchi-api` نسخه سالم قبلی را دوباره فعال کنید، یا موقتاً Route مربوط به `/api/v1/*` را غیرفعال کنید.
2. **تداوم آفلاین بازی:** حتی با قطع کامل `/api/v1/*`، کل ۲۴ مرحله کمپین، چالش روزانه، رقابت دوستانه و ذخیره پیشرفت محلی بدون خطا به کار خود ادامه می‌دهند.
3. **بازگشت فایل‌های استاتیک:** آرشیو قبلی پوشه `dist/` را دوباره در فضای ابری بارگذاری کرده و **کش CDN ابر آروان (Purge Cache)** را پاک‌سازی کنید.
